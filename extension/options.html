Browser extension

Connect to Curio

Paste the connection key created in Curio under My Account.

Connection

HTTPS is required except for localhost development. Only this origin is requested from Chrome.

No connection key is stored.

What this connection can do

  • Save public page links to Curio
  • Read the available tags
  • Confirm which Curio account is connected

It cannot manage members, roles, or Curio settings.

Connection key and revocation

The connection key is stored in chrome.storage.local. Chrome does not provide application-level encryption for this value, so anyone or any software with access to this browser profile may be able to recover it. Never reuse another credential, and revoke the connection from your Curio account if this device is lost or compromised.

Forgetting the key here removes only this browser copy; server-side revocation remains authoritative.
