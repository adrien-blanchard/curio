# Support

Curio is community-maintained software provided without a service-level agreement or warranty.

## Where to ask

- Use Discussions for setup questions, architecture discussions, and usage help when that feature is
  enabled.
- Use the issue tracker for reproducible bugs and focused feature requests.
- Use a private security advisory for vulnerabilities.

Before asking, search existing documentation and reports. Include the Curio version, Node version,
browser, deployment type, relevant sanitized logs, and a minimal reproduction. Never include keys,
tokens, cookies, private URLs, migration exports, personal data, or full environment files.

## Deployment support

Vercel, Supabase, Google Cloud, and Chrome Web Store accounts are operated by their respective
providers. Billing, quota, account recovery, and provider outages must be handled through those
providers. The Curio community can help interpret integration behavior but cannot access or repair
third-party accounts.

## Unsupported requests

Maintainers cannot guarantee support for modified database policies, unpinned forks, end-of-life
Node versions, or deployments that expose service-role credentials to clients.
